# Possible LMX Agents

Open-source, downloadable agents powered by LMX Cloud (inference + settlement baked in).

- **lmx.voice** — Voice assistant agent; talk to it, it answers via LMX-routed inference.
- **lmx.research** — Web research agent; gathers, summarizes, and cites sources on a given topic.
- **lmx.code** — Coding assistant agent; writes, debugs, and reviews code in a local repo.
- **lmx.trader** — Market-watching agent; tracks prices/news and can execute trades via connected wallet.
- **lmx.writer** — Content writing agent; drafts blog posts, emails, and social copy.
- **lmx.social** — Social media agent; schedules and posts content, monitors engagement.
- **lmx.support** — Customer support agent; answers FAQs and tickets for a business's product.
- **lmx.analyst** — Data analysis agent; ingests spreadsheets/CSVs and produces reports/insights.
- **lmx.scheduler** — Calendar/scheduling agent; books meetings and manages availability.
- **lmx.recruiter** — Sourcing agent; screens resumes and drafts outreach for hiring.
- **lmx.legal** — Contract review agent; flags risky clauses and summarizes legal docs.
- **lmx.shopper** — Personal shopping agent; finds and compares products, tracks prices.
- **lmx.tutor** — Learning agent; explains concepts and quizzes users on a subject.
- **lmx.travel** — Trip-planning agent; builds itineraries and books travel.
- **lmx.dev-ops** — Infra monitoring agent; watches deployments/logs and alerts on issues.
